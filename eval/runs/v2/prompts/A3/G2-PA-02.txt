## Speech

Ollama can now generate [speech](https://docs.ollama.com/capabilities/speech) on macOS. `ollama run` plays text or a chat model's reply aloud as the audio is generated, and apps can stream audio through the OpenAI-compatible `/v1/audio/speech` endpoint.

```sh
ollama run phonon "Hello from Ollama."
```

### `/v1/audio/speech`

> Note: Added in Ollama v0.40.8

Generates audio with [speech models](/capabilities/speech). The response streams while audio is generated.

#### Supported request fields

- [x] `model`
- [x] `input` (up to 4,096 characters)
- [x] `voice` (one of the voices `ollama show` lists, in any case and with or without accents, such as `Freya`; omit it for the model's `default` voice)
- [x] `response_format`
  - [x] `wav` (default)
  - [x] `pcm`
  - [ ] `mp3`, `opus`, `aac`, `flac`
- [x] `speed` (`1` only)
- [x] `stream_format` (`audio` only)
- [ ] `instructions`

## Direct cloud access

Set your [API key](https://ollama.com/settings/keys) in `OLLAMA_API_KEY`. No Ollama installation required.

```shell
export OLLAMA_API_KEY="your_api_key"
```

Send a request with bearer authentication:

```shell
curl https://ollama.com/v1/messages \
  -H "Authorization: Bearer $OLLAMA_API_KEY" \
  -H "Content-Type: application/json" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "gemma4:31b",
    "max_tokens": 1024,
    "messages": [
      {
        "role": "user",
        "content": "Say hello in one sentence."
      }
    ]
  }'
```

Read text blocks from `content`. The cloud endpoint requires `Authorization: Bearer`; it does not accept `x-api-key` alone.

Compatible models support messages, streaming, and function calling. Tool-choice controls, deferred tools, and hosted web search are not fully supported.
