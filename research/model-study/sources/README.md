# Model study sources

Model cards and licences read for the study, saved as Markdown. Three large third-party files used during the study are not kept here; fetch them from their publishers if needed: the gpt-oss model card PDF, the HumanEval dataset (`HumanEval.jsonl.gz` from the openai/human-eval repository; `humaneval-commit.json` records the commit used), and the `llama_index_core` 0.10.68 wheel from PyPI.
